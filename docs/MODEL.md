路径只记录编制环境，哈希才是跨机器校验依据。审计产物还会记录当前代码、评分规则、行业数据、依赖清单、Git 提交与运行时版本哈希；因此“补丁6”名称相同但哈希不同的结果不能视为同一模型代。

## 1. 通用约定

- 价格和每股价值的单位是人民币/股；市值、收入、现金流、债务和权益沿用数据源的人民币金额单位；股本是股数。参与同一公式的金额必须来自同一单位口径。
- 比率在引擎内部使用小数，例如 `8%` 表示为 `0.08`。所有输入必须是有限实数；`NaN`、无穷值、布尔值和无法解析的文本均按缺失处理。
- 年度趋势按报告日期排序并按自然年去重，增长率按实际经过的自然年计算，不把季度行数当作年数。非金融估值的 TTM 输入另由 schema 8 的精确报告期合同重构，不能把任意“最新三行”拼在一起。
- 缺失证据不会自动换成有利的正数。估值所需核心字段缺失时，该股票不产生估值结果；定性、监管、治理等评分证据缺失时，状态是“证据不足”而不是公司已经失败，也不能仅凭缺失触发一票否决。若另一项已有完整证据且明确命中硬否决，该否决仍会保留并同时披露其余证据缺口。

## 2. 非金融企业 FCFF DCF

### 2.1 基础现金流、增长与净债务

非金融企业在公开财报字段有限时使用以下现金流代理：

```text
FCF_proxy = 经营活动现金流净额 - |购建长期资产现金支出|
```

生产估值必须从 schema 8 快照的 `reporting_period_contract` 读取三个精确截止日：最近完整年度 `FY`、当前累计报告期 `current YTD`，以及截止月日完全一致的上年同期 `prior YTD`。当前累计期只允许 Q1、半年报或 Q3；报告期合同的公开口径固定为 `FY_plus_current_YTD_minus_prior_YTD`。收入与现金流分别重构：

```text
TTM_Revenue = FY_Revenue + Current_YTD_Revenue - Prior_YTD_Revenue
TTM_CFO = FY_CFO + Current_YTD_CFO - Prior_YTD_CFO
TTM_Capex = |FY_Capex| + |Current_YTD_Capex| - |Prior_YTD_Capex|
TTM_FCFF_proxy = TTM_CFO - TTM_Capex
```

每个组件必须恰好命中一条同口径财报记录；缺失、重复、非有限或重构后资本开支为负都会使该公司本次非金融估值失败。资本开支优先采用紧凑现金流表直接披露值；该字段为空时，仅当详细现金流表的投资现金流出恒等式能够唯一证明资本开支为 0，才写入带公式、分项、报告期和来源 URL 的 `derived_calculation` 证据。正残差、负数重分类、无法闭合的恒等式或整行空白都继续保持缺失。TTM 收入和 TTM `FCFF_proxy` 还必须为正。生产路径没有年度回退，也不会把缺失资本开支当作零。

基础现金流只在严格 `[FY-1, FY, TTM]` 三期序列上归一化，零值和负值不会被过滤。通常取三期中位数，但受两道防线约束：TTM 非正时直接采用该非正值并拒绝正估值；三期持续下降时采用 TTM；其他情况下中位数最多只能高于最新正 TTM `FCFF_proxy` 25%。若历史利润同时跨越亏损与盈利且最近三年没有连续复苏，还会用全部可复算完整年度 FCFF 的下四分位进一步封顶；下四分位非正时不估值。基础现金流、TTM 收入或股本非正时不构造正估值。输出以 `valuation_input_basis="strict_ttm"`、`base_revenue_basis="strict_ttm_reported_revenue"` 和 `fcf_normalisation_period_basis="two_annual_plus_strict_ttm"` 明确标记这一口径，并保留 TTM 三组件及归一化周期证据。

该代理不是会计学意义上的严格 FCFF：现金流量表中的经营现金流通常已经包含利息及营运资本影响，模型没有逐公司重构税后利息、债权人现金流或租赁调整。因此它只适合第一层量化筛选，不能替代完整三表预测。银行、保险和证券公司禁止使用该代理评分或估值。

收入 CAGR 需要至少三个有效自然年，并按首末报告年份的真实间隔计算；DCF 增长趋势只回看最近五个有效自然年，不能把这个增长估计窗口误解为财务历史只有五年。年报证据层独立抓取最近十个完整年度，Type 4 护城河耐久度也按可用的十年证据判断。CAGR 结果限制在 `[-10%, 50%]`。情景增长综合近期加权趋势、趋势斜率及波动，并在存在公司增长证据时才混合行业基准。完全没有增长证据时，悲观、中性、乐观三种增长率均为 `0%`，不会凭行业均值制造增长。只有两个有效年度时会明确标记为有限历史证据。

净债务为有息债务减货币资金：

```text
NetDebt = GrossInterestBearingDebt - Cash
```

有息债务优先使用数据源直接给出的有息负债合计，否则仅汇总短期借款、短期应付债券、长期借款、应付债券、一年内到期长期债务和租赁负债等明确有息项目；不使用总负债替代。若债务字段整体不可得，则净债务采用中性 `0`，也不会仅凭现金字段推导“净现金”。

### 2.2 Beta、资本成本与 WACC

当前风险参数的日期和来源注释保存在 `config.py`。CAPM 的两个市场输入保留各自日期，不能用最新一个日期覆盖另一个：无风险利率为中债国债收益率曲线 10 年期 `1.7406%`（`2026-07-15`）；ERP 为 Damodaran 国家风险溢价工作簿中 China 的 rating-based total ERP `5.7996717401%`（`2026-04-01`，文件 SHA256 `2BCFAACE0EE4132CED6039EA0A2F26999AF8D5366F8FBDE81CF71DFB2735566E`）。模型运行不在线抓取这两个数；外部刷新失败或传入零值、残缺元数据时，使用上述固定官方快照，并在结果的 `risk_parameters.mode/fallback_reason` 中披露，绝不会把失败静默变成零利率或零 ERP。

行业 Beta 与行业债务成本仍来自 `2026-01-05` 的 China 行业工作簿，复算时应同时核对以下 SHA256：

```text
betaChina.xls  FF9187E1CA2DC5EE697E240D368F5C8F1956BC00C4FF8E8B0B0D46C698F2AEE9
waccChina.xls  525FF4A15A2585FD2D1C06FC758296654370837DA95E7107F64A14B0F03667A6
```

```text
βL = βU × [1 + (1 - T) × D / E]
Ke = Rf + βL × ERP
WACC = E/(D+E) × Ke + D/(D+E) × Kd × (1-T)
```

其中 `E = 当前股价 × 总股本`，`D` 为有息债务，`T` 为可实现税盾率，`Kd` 为行业税前债务成本。当前上游合同没有利润总额、所得税费用或现金税证据；经营利润为正不能证明利息后应税所得为正，因此实现中将 `T` 保守设为 `0`，不会凭经营利润虚构 25% 债务税盾。Beta 只加杠杆一次。债务或市场权益口径不可靠时，明确退回股权成本 `Ke`，不虚构低成本债务权重。

调用方可为单家公司预取 156 个周收益率的个股 Beta（前复权个股相对沪深300，1%/99% 分位缩尾并作 Blume 调整）。它是已加杠杆股权 Beta，只能与已经按公司资本结构加杠杆后的行业 Beta 比较。样本不足、代码不匹配、截至日超过 21 天、来源缺失、`R²<5%` 或结果不可用时，权重为零；通过闸门后个股权重为 `min(50%, R²)`，行业权重为其余部分。即使 `R²=100%`，个股价格 Beta 也不会完全覆盖行业先验。结果保留 raw/Blume Beta、R²、样本数、起止日、来源、缓存命中和最终权重。全市场批量估值默认不抓取个股历史行情，只消费显式传入的预计算映射，因此不会为数千家公司逐一同步联网；北交所代码不会进入该映射。

### 2.3 显式期、终值和每股价值

显式预测期 `N=5` 年。对第 `t` 年：

```text
Revenue_t = Revenue_0 × (1 + growth)^t
FCFF_t = Revenue_t × Margin_t
PV_explicit = Σ[FCFF_t / (1 + WACC)^t]
```

`Margin_t` 从当前 FCFF 利润率线性回归至长期目标利润率。普通公司的悲观/中性/乐观利润率保留比例分别为 `40%/60%/85%`；只有通过连续多年盈利、归母 ROE、利润率稳定性以及包含零/负年份的完整 FCFF 证据后，才使用 `70%/80%/90%`。即使属于高质量公司也不保留 100% 超额利润率。普通公司进入估值前的当前 FCFF 利润率还会按 `min(25%, max(8%, 行业长期目标×3))` 封顶；高质量公司只保留一个防异常的 `65%` 上限。长期均衡利润率参考值为 `4%`、统一地板为 `0%`，但目标值始终不高于公司当前利润率，因此模型不会为低利润率公司凭空扩大利润率。

Gordon 终值使用显式期之后的第 `N+1` 年现金流：

```text
FCFF_(N+1) = Revenue_N × (1 + g∞) × Margin_target
TerminalValue_N = FCFF_(N+1) / (WACC - g∞)
EquityValue = PV_explicit + TerminalValue_N/(1+WACC)^N - NetDebt
ValuePerShare = EquityValue / SharesOutstanding
```

必须满足 `WACC > g∞`，且最终每股价值为有限正数。常规公司的悲观/中性/乐观永续增长率分别为 `0%/1%/2%`；若最近四个有效年度收入逐年下降，模型把三种永续增长率收紧为 `-2%/-1%/0%`，不会给结构性衰退公司强加正增长。WACC 情景偏移分别为 `+1.0/0/-0.5` 个百分点。每个情景再以 `±0.5` 个百分点的折现率形成上下沿；较高折现率对应价值下沿。

三个情景必须按经济结果单调排列。买入区上界是“悲观上沿与中性下沿”的均值；卖出区下界是“中性上沿与乐观下沿”的均值。当前价位于两者之间时为观察区。`valuation_center` 与 `neutral_value_midpoint` 都明确表示中性情景上下沿的中点；历史字段 `dcf_value_mean` 实际是买入区上界，为兼容旧导出暂保留，并由 `dcf_value_mean_legacy_alias_of="buy_zone_upper"` 明确标识，不得再称为“DCF 均值”。

### 2.4 Type 4 的独立十年终局面

常规买入区仍使用上述五年显式预测面。Type 4 另行生成 `dcf_10y_points`：显式期为 10 年，情景增长率逐年线性衰减至对应永续增长率，不能用未标注的五年常增长面冒充。`4d` 比较当前价格与十年中性情景上下沿中点；`4f` 使用乐观情景上沿参数反推当前价格需要透支的高增长年数。十年面缺失只会使 Type 4 估值证据不完整，不会篡改已经有效的五年 DCF 买入/观察/卖出区。

## 3. 金融企业 justified P/B

银行、保险和证券公司不使用工业企业 FCFF/WACC。存款、保单负债等属于经营投入，不能直接按普通融资负债处理。

金融估值要求至少三个共同自然年的归母净利润与归母权益，最多使用最近五年，且至少 `80%` 的年度 ROE 为正：

```text
AverageParentEquity_year = (ParentEquity_(year-1) + ParentEquity_year) / 2
ROE_year = ParentNetProfit_year / AverageParentEquity_year
NormalisedROE = median(ROE_year)
BVPS = LatestParentEquity / SharesOutstanding
Ke = Rf + FinancialLeveredBeta × ERP
JustifiedPB = (ScenarioROE - g) / (Ke - g)
ValuePerShare = BVPS × JustifiedPB
```

悲观 ROE 取 ROE 下四分位与标准化 ROE 的 `80%` 中较低者；中性取中位数；乐观取 ROE 上四分位与标准化 ROE 的 `110%` 中较低者，但不低于中性 ROE。常规正 ROE–资本成本差公司的悲观/中性/乐观增长目标为 `0%/1%/2%`；最近四个有效年度归母利润逐年下降时改为 `-2%/-1%/0%`；当标准化 ROE 不高于股权成本时，继续再投资会毁损价值，因此三种目标反向为 `2%/1%/0%`，使更低留存增长对应更乐观结果。最终增长率还同时受不低于 `-3%` 的目标地板、情景 ROE 的 `50%` 和 `Ke-2%` 上限约束。要求 `ScenarioROE > g` 且 `Ke±0.5% > g`；`Ke±0.5%` 生成每个情景的 P/B 上下沿。缺少归母权益时不会用总权益悄悄替代。

同一股权成本区间会使相邻 P/B 不确定性带自然重叠，因此金融估值不要求三个带完全分离；但每个带必须为有限正数且下沿不高于上沿，悲观/中性/乐观带的中心必须依次不降，并且买入区上界不得高于卖出区下界。非金融 DCF 仍要求三个情景带完全有序且不重叠。

金融评分另行读取同一年度主财务指标中的行业专属字段，不再用 ROE、利润或工业现金流弱代理冒充监管质量：银行使用净息差、净利差、资本/一级资本充足率、不良贷款率、贷款拨备率及存贷款；保险使用综合偿付能力、新业务价值及价值率、已赚保费和退保率；证券公司使用风险覆盖率、资本杠杆率、流动性覆盖率、净稳定资金率、净资本/负债及风险资本准备。原始字段统一标为“数据商标准化字段”，公式项统一标为“公式推导”，缺失则标为“缺失”；贷款拨备率/不良贷款率只称“覆盖代理”，不会冒充公司直接披露的拨备覆盖率。

硬监管边界分别绑定[商业银行资本管理办法](https://www.gov.cn/gongbao/2024/issue_11126/202401/content_6928796.html)、[保险公司偿付能力监管规则](https://www.nfra.gov.cn/chinese/docfile/2022/5d6576679eaa45d3b4ea34fb7adb1254.pdf)和[证券公司风险控制指标管理办法](https://www.csrc.gov.cn/csrc/c106256/c1653957/content.shtml)。高于最低线的“强缓冲”、不良率、净息差、新业务价值率和退保率分档是 `financial-sector-evidence-v1` 的透明筛选假设，不是监管结论；单家公司可能还适用系统重要性、第二支柱或其他附加要求。

## 4. 补丁7七类买入评分（情况七使用补丁6分类）

每个子项先清洗到 `[0,10]`，按下表权重加总并四舍五入到一位小数。类型总分只有达到 `7.0`、证据完整且未触发一票否决或额外条件时才触发。每个子项的展示证据最多 20 个字符；完整数值、公式与来源保留在结构化账本。缺失定性或监管数据会标为证据不足，不用行业故事补分，也不等同于确认失败。

| 类型 | 子项与权重 | 一票否决或强制规则 |

一只股票可以同时触发多类。`primary_type` 只表示触发类型的业务优先级；`diagnostic_type` 和“诊断最高分”必须始终表示七类中实际总分最高者，两者不能混用。原六类优先级保持不变；Type 7 原文没有规定覆盖顺序，因此追加在后，避免改写既有主类型语义：

```text
Type 1 > Type 2 > Type 5 > Type 3 > Type 4 > Type 6 > Type 7
```

### 4.1 Type 5 强周期底部的专用证据

最新《补丁7》情况五附录只把 `5a ≥ 7` 规定为适用硬门槛；进入“最佳买点”还要求 `5b–5e` 证据完整且五项固定权重总分达到7分。附录没有规定 `5c ≥ 5` 的独立触发门，也没有 `5a ≤ 3` 或 `5c ≤ 3` 的一票否决，因此程序不会擅自增加这些条件。`5c` 仍按20%权重真实进入总分，抗周期能力差会降低结果，但不会被重复计算成另一道门槛。规则绑定文档哈希，不能由运行时数据或个别公司结果临时切换。

Type 4 的 `4a≥5` 是程序根据原模板“5–6分为中坡”设定的最低触发资格，用于避免短坡公司因其他高分而被标为长坡；原模板没有直接写出这道数值门槛，也不把它视为一票否决。

Type 5 是强周期估值的附加纪律，不是“利润刚回升”的通用筛选器，也不会取代 Type 1 的 DCF。只有 `5a` 已确认强周期属性时才进入该框架：产品有公开大宗价格周期、毛利率跨周期波动超过 15 个百分点、行业经历产能出清/扩张、盈利高度绑定单一商品价格，四项多数成立即为 `5a≥7`。程序仅会在煤炭、油气、钢铁、有色、基础化工、建材等窄口径大宗行业，同时观察到多年毛利率和利润周期波动时自动确认最低 7 分。新浪期货的一条行业参照序列只提供商品行情背景，即使绑定到公司代码也不得单独确认 5a；必须同时由该公司的连续毛利率跨周期波动和利润周期共同印证，此时只确认 `5a=7`，不因行业价格振幅大而给公司9–10分。航运、猪周期、面板、光伏链等宽口径行业必须导入可追溯的原始行业证据，避免把整个大类误判为强周期。

`5b` 必须由“自身 5–10 年 PB 分位/重置成本/价格相对现金成本/产能利用率或库存”支撑；`5c` 由净现金、低负债与成本曲线、产业资本并购价或可持续分红共同支撑；`5d` 必须有供需缺口或产能释放的弹性证据；`5e` 必须以 5–10 年完整年度归母净利均值计算正常化 PE，并结合历史中位水平判断，禁止采用当年 PE。当前公开快照没有行业成本曲线、库存/利用率、重置成本和产业资本并购数据库时，程序会保留可复核的资产负债表、利润振幅和正常化 PE 诊断，但显示“证据不足”，绝不触发买入。

页面不接受手填的 Type 5 结论分数。`type5_cycle_attribute_score`、`type5_bottom_signal_score`、`type5_survival_score`、`type5_upside_elasticity_score`、`type5_normalized_earnings_score` 等 0–10 分字段即使附带来源和日期，也不能从 JSON 导入并参与买点判定。当前生产路径只采用可由行情、财报、五年 PB 历史和结构化原始事实逐项复算的结果；尚无结构化适配器的数据继续显示“证据不足”。

Type 6 只表示高风险候选属性。它允许“亏损仍在但精确同报告期同比收窄”的反转候选；若经营现金流仍为负但同比改善，`6d` 仍封顶 4 分并明确披露现金消耗风险，不把现金消耗当成正向证据。利润或现金流为负且缺精确同报告期比较、从非负转负或继续恶化时会严格压低 `6d`，但不会凭缺失比较另造补丁6否决；完整技术/模式证据下，6a–6d 少于两项达到 5 分才形成该项硬否决。高景气技术型建议单票 `≤1%`、同类组合 `≤8%`，平稳产业反转型建议单票 `≤3%`、同类组合 `≤15%`；统一硬上限仍为单票 `5%`、同类组合 `15%`，并按“判断错误时单票可损失全部仓位”披露最大损失。它不是常规核心持仓建议。

### 三条空头弱点

每个结果都为主类型生成恰好三条 `bear_case`，用于迫使研究者先看最致命的反方证据。排序完全确定：先列一票否决、额外条件或泡沫降级等元信息；不足三条时，再按子项分数从低到高补齐。同分时先选权重更高的子项，仍同分则按子项定义顺序。每条仅包含维度、0–10 分和不超过 20 个字符的证据说明，不生成买卖指令。

## 5. 数据晋级、分析边界与审计

- schema 8 快照验证先检查行情身份、每行源交易日期/时刻、每行获取时间、价格/市值单位及分布、沪深市场绝对与相对覆盖、财报字段、连续自然年、报告期、资本开支来源证明、上市日期来源证明、Type3 商誉/并购现金流源字段存在性和行业数据健康度。全市场代的上市日期参考覆盖与有效日期覆盖均不得低于 99%；上市日期晚于源交易日、来源不符、时间戳无时区或来自未来都会拒绝整代。年度历史审计只从可靠上市年份开始计缺口，未知上市日期则保持未知并按完整观察窗保守检查。每代还必须生成唯一 `reporting_period_contract`，并在沪深非金融分母上分别核验严格 TTM 收入和 FCFF 源覆盖；金融企业与北交所不进入该分母。源行情时间晚于快照或陈旧超过允许窗口时整代拒绝；schema 4 缺少报告期合同，schema 5 未强制资本开支来源证明，schema 6 缺少独立上市日期来源证明，schema 7 未强制保存 Type3 补充字段存在性，均不能冒充当前代。
- `eligible_codes` 是唯一允许进入对应估值模型与七类型评分的股票集合。每家公司还必须存在于规范化行情和财报输入中，并具备当期核心财报；财报不完整、退市整理、风险状态或无法形成可靠参考价的记录仍可保留在原始行情中，但必须带排除原因，不得自动形成买入候选。
- 新抓取数据只是候选代。评分覆盖、估值尝试/有效覆盖、异常率以及与上一代的相对变化全部通过分析质量闸门后，才能晋级。已有活动代时，compare-and-swap 必须同时匹配上一代 `data_timestamp` 和规范化 payload SHA256；同时间戳异内容、较旧候选、获取时间倒退或任一令牌缺失/不匹配都不能覆盖活动代。
- UI 持久保存并导出估值模型、悲观/中性/乐观六个端点、参数、严格 TTM 组件与报告期依据、逐公司跳过原因和质量覆盖率。非金融企业使用严格 TTM 输入的 FCFF DCF，金融企业走独立 justified P/B 分支；“估值跳过”不等于管线成功估值，“证据不足”也不等于公司不符合，不能用总计数替代分母、覆盖率和原因。
- 固定种子随机审计必须显式使用 `eligible_codes`，行业横截面基准由完整 eligible universe 构造后再抽取样本。引擎自身不变量检查与独立重算分别报告；同源结构校验不能被包装成独立审计。JSON 产物保存完整子分、依据、估值明细和全部可复现哈希。

行情时间语义必须保守：`source_trade_date` 与 `quote_tick_time` 表示上游报告的成交日期/时刻，`retrieved_at` 只表示系统获取数据的时间。三者不得互相冒充；周末、休市或上游缓存响应不能因为刚被系统获取就称为“实时成交”。

行情 PE 与滚动 PE 也不得混用。当前新浪行情 `per` 字段保留为行情 PE，并非 `PE_TTM`（例如 2026-08-28 吉比特 15.586 倍对应上年度盈利，而按新半年报滚动计算约为 12.48 倍）。它不得覆盖东财历史分布的 `current_pe_ttm`。复用历史缓存时，只有显式的当期 `pe_ttm` 才能重算 PE 分位；否则只使用可独立重算的 PB 分位，同日已有的 TTM 原始观察仍可使用。AI 如另算 TTM，必须注明财报期间及计算口径，不能把行情 PE 改名为 TTM。

## 6. 缺失策略与已知局限

- 行情和财报来自第三方公开接口，可能受字段调整、停牌、网络限流、报告修订和缓存影响。结构/数量/单位异常可以被拒绝，但校验不能证明数据在经济意义上绝对正确。
- 行业分类以中国上市公司协会公布的证监会行业分类结果为第一权威层，生产数据保存统计期、原始 PDF URL、SHA256 和逐股票门类代码；统计期后上市公司由交易所上市文件逐只补录。实时 F10 的明确行业字段可以覆盖官方统计期后的空档或提供更细分类，但必须保留来源层级。名称关键字只作为诊断性回退，不计入“可绑定来源覆盖”；任一沪深 eligible 股票没有可绑定来源或不能映射到模型行业时，行业健康闸门失败。北交所不在投资分析范围，也不进入覆盖率分母。官方权威覆盖和可绑定来源覆盖分别报告，不能把后者 100% 表述成官方名单已覆盖所有期后新股。`ALCOHOL` 对应来源中的“酿酒行业”，包含白酒、啤酒、葡萄酒和黄酒等上市公司；输出不得把该宽口径同行聚合误称为“白酒同行”。未知行业不得把互不相关公司混成一个“行业热度”样本；行业 Beta、债务成本和估值基准也不能替代公司级研究。
- 严格 `[FY-1, FY, TTM]` 归一 FCFF DCF 不适合尚未形成正现金流、重大重组或需要逐业务预测的公司；模型对此返回无估值，而不是回退年度数或人为构造扭亏路径。
- 财报中的资本开支、债务与归母权益字段只在明确口径可得时使用。租赁、表外融资、受限现金、少数股东权益或金融工具分类差异仍可能需要人工调整。
- 金融 justified P/B 对正常化 ROE、Beta 与长期增长率敏感。当前量化层已显式接入银行资本/不良/拨备、保险偿付能力/新业务价值和券商净资本/流动性指标，但这些是第三方标准化年度字段与透明阈值，不是完整信用成本、内含价值、核心偿付能力、分部预测或逐公司第二支柱模型；金融机构现金流量表仍不能套用工业企业 FCF/OCF 评分代理。
- Type 2 的“市场冷度”只接受与证券代码、交易日绑定并可独立重放的60日涨跌、年初至今涨跌、换手率和量比记录；估值高低不再代替市场冷度。它仍不是完整的资金流、持仓拥挤或投资者情绪调查，展示和人工解读不得扩大其含义。
- Type 1 的价值陷阱/催化剂、金融机构监管质量，Type 3 的护城河/增长质量/可持续性/泡沫与同口径 ROIC/WACC，以及 Type 4 的坡长/护城河/产业泡沫等，都要求对应可追溯证据；缺失时是未证明，不是通过，也不是确认否决。
- Type 6 的技术壁垒与商业模式分数只接受外部、可追溯的原始证据。自动财报/行情链不生产这两项，因此不能把利润率或增长率伪造成定性证据。
- Type 7 的12个子指标中，财报可复算结果与行业代理会明确区分；代理分有固定上限，不能改标签或抬高上限。品牌、复购、专利、平台锁定、资源稀缺、成本曲线、市场空间等当前仍可能由结果代理近似，不能把“质量认证”理解为已经完成公司尽调。所有直接定性分必须携带与公司代码和快照日期绑定、未过期的证据对象；缺失时只显示上下界。五年PE/PB只服务强科技/强周期价格路径，不代表未来必然均值回归；旧三份百分制账本继续保留用于比较模型迁移，但其结果不能决定当前第七类。
- 七类评分是基于可得量化代理的筛选器。管理层质量、会计政策、行业竞争、重大诉讼、监管处罚和公司治理仍需公告、访谈及独立研究验证。
- 任何历史回测、固定种子抽样或测试通过，都只证明代码在相应输入和断言下保持一致，不证明未来收益，也不排除未覆盖的数据源错误。
